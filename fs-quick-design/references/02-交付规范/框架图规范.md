# 框架图规范（S2b）

> **本文件讲"图该画成什么样"（语义规则）；"怎么生成"见 `SVG生成规范.md`。**
> ⚠️ **生成一律走脚本**（`gen_ui_svg.py` 的 `biz_swimlane` / `tech_layers`）——
> 本文件第四节的 SVG 骨架**只作兜底**，脚本覆盖不了时才手写。
> 实测教训：手写这两张图，一处标签栏盖住图标题、一处来源标记标错行，返工 6 轮。

> 两张图分工不同，**不要合并成一张**：业务图回答"业务怎么走"，技术图回答"系统怎么搭"。
> 一律**内联 SVG**写在产出 MD（`30-FS-<需求名>.md`）的「4 业务框架图」「5 技术框架图」章节里
> （不用外部图片、不用 canvas），**浅色主题**（可打印、可投屏、可在 Markdown 预览里直接看）。

## 一、业务框架图 = 泳道图

**布局铁律（既定团队规范，不许改）**

| 维度 | 规则 |
|---|---|
| **水平泳道** | = **角色**（业务员 / 主管 / 系统 / 财务 …），一条泳道一个角色 |
| **垂直列** | = **业务步骤**，从左到右按时间顺序 |
| 泳道标签 | 固定在左侧栏，宽度 120px，深色文字 + 浅底 |
| 交叉格 | 该角色在该步骤不做事的格子留空（不要填"无"） |

**形状约定（不许自创）**

| 形状 | 代表 |
|---|---|
| 圆角矩形 | **人 / 角色动作** |
| 文档形（底部波浪或右上折角） | **数据 / 单据 / 报表** |
| 六边形 | **系统 / 程序** |
| 菱形 | **判定**（业务分支） |

## 二、技术框架图 = 分层数据流

固定四层，自上而下，**节点写真实 SAP 对象名**（把勘察结论可视化）：

| 层 | 内容 | 节点示例 |
|---|---|---|
| **L1 触发层** | 入口：选择屏 / 事务码 / 上载文件 / 接口 | `SE38 ZSD_XXX` · 上载 `.XLSX` |
| **L2 逻辑层** | 校验 / 计算 / 规则 | `FORM f_check_data` · 校验规则 3 条 |
| **L3 数据层** | 取数与落库对象 | `VBAK` `VBAP` `BAPI_SALESORDER_CREATEFROMDAT2` |
| **L4 输出层** | 结果去向 | `ALV 结果列表` · `日志 BAL` · `接口回写` |

**连线**：自上而下**单向**，一条主线 + 异常/旁路（细虚线）。
**数据层（L3）的每个节点必须在右上角标来源级别** `[L1]` / `[L2]` / `[L3]`（与勘察结论一致）——
让开发一眼看出哪个技术事实还没落系统核实。触发层/逻辑层/输出层是方案设计，不必标。

## 三、配色（浅色主题 · 锁定）

| 用途 | 填充 | 边框 | 文字 |
|---|---|---|---|
| 画布 / 泳道交替底 | `#FFFFFF` / `#F7F9FB` | — | — |
| 泳道标签栏 | `#EEF3F8` | `#D6DEE7` | `#1A1A1A` |
| **人 / 角色**（默认节点） | `#FFFFFF` | `#B0BEC5` | `#1A1A1A` |
| **系统 / 程序** | `#E8F1FB` | `#93B2D0` | `#1A1A1A` |
| **成功 / 正常完成** | `#E8F5E9` | `#81C784` | `#1A1A1A` |
| **异常 / 错误分支** | `#FFF3E0` | `#FFB74D` | `#8A4B00` |
| 连线 / 箭头 | — | `#90A4AE` | — |
| 次要说明文字 | — | — | `#5A6B7B` |

**字体**：`"Microsoft YaHei","Arial",sans-serif`。
**字号**：图标题 14px bold、泳道/层标签 12px bold、节点文字 12px、来源级别 9px。
**尺寸**：`viewBox="0 0 1200 <高>"`，容器内 `width:100%;height:auto`，最小宽度 1200 保证不挤压。

## 四、SVG 骨架（照此结构输出）

```html
<svg viewBox="0 0 1200 460" width="100%" style="min-width:1200px;font-family:'Microsoft YaHei',Arial,sans-serif">
  <!-- 画布 -->
  <rect x="0" y="0" width="1200" height="460" fill="#FFFFFF"/>

  <!-- 泳道底：交替 #FFFFFF / #F7F9FB -->
  <rect x="0" y="40" width="1200" height="100" fill="#F7F9FB"/>
  <rect x="0" y="140" width="1200" height="100" fill="#FFFFFF"/>

  <!-- 泳道标签栏 -->
  <rect x="0" y="0" width="120" height="460" fill="#EEF3F8"/>
  <line x1="120" y1="0" x2="120" y2="460" stroke="#D6DEE7"/>
  <text x="60" y="95" text-anchor="middle" font-size="12" font-weight="bold" fill="#1A1A1A">业务员</text>
  <text x="60" y="195" text-anchor="middle" font-size="12" font-weight="bold" fill="#1A1A1A">系统</text>

  <!-- 列分隔（业务步骤） -->
  <line x1="400" y1="0" x2="400" y2="460" stroke="#E3EAF1" stroke-dasharray="3 3"/>

  <!-- 节点：人（圆角矩形） -->
  <rect x="150" y="70" width="140" height="40" rx="5" fill="#FFFFFF" stroke="#B0BEC5"/>
  <text x="220" y="94" text-anchor="middle" font-size="12" fill="#1A1A1A">上载 Excel</text>

  <!-- 节点：系统（六边形） -->
  <polygon points="440,70 570,70 585,90 570,110 440,110 425,90" fill="#E8F1FB" stroke="#93B2D0"/>
  <text x="505" y="94" text-anchor="middle" font-size="12" fill="#1A1A1A">校验并创建订单</text>

  <!-- 节点：异常（浅橙） -->
  <rect x="700" y="170" width="140" height="40" rx="5" fill="#FFF3E0" stroke="#FFB74D"/>
  <text x="770" y="194" text-anchor="middle" font-size="12" fill="#8A4B00">写入错误日志</text>

  <!-- 连线（带箭头，用 marker 或三角 polygon） -->
  <line x1="290" y1="90" x2="425" y2="90" stroke="#90A4AE" stroke-width="1.4"/>
  <polygon points="425,90 418,86 418,94" fill="#90A4AE"/>
  <line x1="505" y1="110" x2="505" y2="190" stroke="#90A4AE" stroke-width="1.2" stroke-dasharray="4 3"/>
</svg>
```

> **连线画法**：折线用 `<polyline fill="none" stroke="#90A4AE">`，箭头用 `<polygon>` 三角（不依赖 `marker`，避免不同浏览器渲染差异）。
> **文字不换行**：SVG `<text>` 不自动换行，长文案要么缩短，要么手动拆成多个 `<tspan>`。

## 五、自检清单（出图前逐条过）

- [ ] 业务图：泳道 = 角色（不是步骤）、列 = 步骤（不是角色）—— **最容易画反**
- [ ] 业务图：每条泳道标签是**具体角色名**（不是"用户"），且没有出现技术对象名
- [ ] 技术图：四层齐全，节点是**真实 SAP 对象名**（不是"数据库""接口层"这种空泛词）
- [ ] 技术图：数据层（L3）每个节点标了 `[L1]`/`[L2]`/`[L3]`，且标记落在**对应节点的**右上角
- [ ] **左侧标签栏从泳道/分层区顶部（约 y=48）开始**——不要从 y=0 起，
      否则会盖住图标题（实测踩过：标题只剩后半截）
- [ ] 异常分支用浅橙，成功路径用浅绿或默认白/浅蓝
- [ ] 文字没有溢出节点（估算：中文 ≈ 12px/字，节点宽 ≥ 字数×13 + 24）
- [ ] 整图在 1200px 宽下不挤压、不重叠
